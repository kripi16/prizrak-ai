ПРИЗРАК AI — сайт + устанавливаемое веб-приложение

Что входит:
- адаптивный чат для телефона и компьютера;
- история чатов сохраняется локально в браузере;
- PWA-файлы для добавления на главный экран;
- серверный маршрут /api/chat для подключения Gemini API;
- ключ Gemini хранится на сервере хостинга, а не в браузере.

Как опубликовать (можно сделать и с телефона):
1. Создай аккаунт на GitHub и новый репозиторий.
2. Загрузи в репозиторий все файлы и папку api из этого архива.
3. Импортируй репозиторий в Vercel и нажми Deploy.
4. Получи ключ Gemini API через Google AI Studio (проверь доступность и условия бесплатного тарифа в своём регионе).
5. В настройках проекта Vercel → Environment Variables добавь:
   GEMINI_API_KEY = твой ключ
   GEMINI_MODEL = gemini-2.5-flash
6. Сделай Redeploy.
7. Открой опубликованный сайт по ссылке. В браузере Android можно выбрать меню ⋮ → «Добавить на главный экран» / «Установить приложение».

Важно:
- Бесплатный тариф ИИ может иметь лимиты и правила, которые меняются; бесплатность не гарантируется навсегда.
- Не отправляй свой API-ключ в чат и не вставляй его в публичный код.
- Переписки в этой стартовой версии сохраняются в браузере конкретного устройства, а не синхронизируются автоматически между телефоном и ПК.
- Для синхронизации истории между устройствами позднее добавим авторизацию и базу данных.
- Чтобы проверить интерфейс без публикации, открой index.html, но серверный ИИ работает только после публикации на совместимом хостинге.
